# PokéSurvivor 广域资源地图与一键汉化 v1.7.2

## 简洁地图（v1.7.2）
- 地图默认仅显示地图画面和“显示详细信息”按钮。
- 点击后展开地图状态、缩放/回中操作、资源筛选和图例，再点“隐藏详细信息”收起。
- 简洁模式仍可滚轮缩放、拖动地图和拖动标题栏。

## 悬浮按钮移动（v1.7.1）
- 折叠地图或按 M 隐藏后，可按住小地图悬浮按钮拖动位置，支持鼠标和触屏。
- 轻点仍会展开地图；拖动松手不会误展开，按钮不会被拖出屏幕。

## 一键汉化（v1.7 新增）
- 游戏页面右下角新增 **一键汉化** 按钮，点击开启简体中文，再点 **中文已开 · 恢复原文** 即可关闭，无需重开对局。
- 宝可梦、招式和携带道具采用专用中文名称，覆盖菜单、卡牌说明、任务、成就、联机提示，以及游戏 Canvas 绘制的战斗文字。
- 汉化使用随扩展打包的本地词库，不调用翻译服务。首次默认关闭，开启后会记住选择（同一浏览器、同一网站来源）。
- 原小地图脚本与功能保持不变，汉化按钮独立于小地图显示。
- 已加载过本文件夹的用户：到 `edge://extensions/` 或 `chrome://extensions/`，点击此扩展的**重新加载**，再刷新游戏页面即可；不必删除扩展，也不会清除游戏存档。
- 使用汉化时请关闭浏览器自带的网页翻译，以免两套翻译重复处理文本。
- 词库范围、维护方式与验证记录见 [TRANSLATION.md](TRANSLATION.md)。

## 功能
- 不是截图缩放。根据游戏绘制时产生的地图区块信息建立地图，覆盖数个游戏画面。
- 在地图上叠加独立资源标记：小宝箱（chest，可击碎）、大宝箱（bigchest，靠近解锁）、增益祭坛、治疗泉水，以及可选陷阱、岩石、树木。
- 实心图标来自游戏在本局实际生成过的区块；空心图标是使用项目公开的确定性地图生成算法预测的未加载区块。
- 通过游戏 Canvas 绘制的坐标变换确定当前镜头中心，不依赖 window.G。
- 资源点击可查看世界坐标和约略距离；按 M 显示/隐藏；缩放、拖动、资源筛选、回中。

## 宝箱图标与筛选（v1.6 新增）
- 小宝箱：小型金棕色像素箱，底色金黄，内部类型 `chest`，通过攻击打碎。
- 大宝箱：比小宝箱大一圈的紫金像素箱，正面画有金色锁，底色紫色，内部类型 `bigchest`，靠近等待解锁。
- 两类分别有独立开关，可只保留大宝箱来规划路线。地图下方还显示当前显示范围内的已确认/预测数量。
- **来源区别不变**：实心圆是本局已加载区块，深色空心圆与虚线圈表示根据种子推算的区域。预测资源可能已被队友拾取或受事件影响。

## 安装
1. 在 Edge 打开 `edge://extensions/`，或 Chrome 打开 `chrome://extensions/`，开启开发者模式。
2. 解压 ZIP，点击“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。请确保仅启用一份本扩展。
3. 打开 https://pokesurvivor.com/en/，强制刷新（Ctrl+Shift+R）。
4. 请从**主菜单开始新的一局**，以便在游戏初始化之前记录地形随机种子。
5. 左上角出现“广域资源地图”后，可点“－ 更广”以扩大覆盖范围；按 M 隐藏和恢复。

## 准确度限制
- 已生成区块中的标记可对应当局资源对象，并随着游戏移除的资源更新。
- 未加载区块的标记是按 2026-10-15 公开的 world.js / util.js 规则推算的。只有插件识别出本局种子且确认真实地形吻合，才开启这部分内容；否则未知区域以深色表示，而非编造宝箱位置。
- 祭坛等使用状态以游戏已加载区块为准；远处预测不能保证对象没有被其他队员使用，或没有被裂隙等动态事件覆盖。
- 位置追踪采用镜头中心，并非直接读取玩家角色脚底坐标；运动中可能有少量偏移。
- 如果游戏以后更新其地图算法或打包方法，预测及收集可能失效。
- 本插件仅为个人、本地、非商业的辅助工具。不会上传游戏数据、改变游戏角色或远程调用接口；但在联机游戏里使用地图预测可能构成不公平信息优势，请遵守游戏规则。
- 尚未在官方线上对局中验证，仅适配公开代码并进行本地模拟测试。
